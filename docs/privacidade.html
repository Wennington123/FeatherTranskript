Política de Privacidade

Última atualização: novembro de 2026.

1. Resumo

O FeatherTranskript foi projetado para funcionar 100% no seu dispositivo. Não coletamos, armazenamos, transmitimos nem vendemos seus áudios, textos ou dados pessoais.

2. Processamento de áudio

Os arquivos de áudio que você seleciona são processados localmente, pela CPU do seu computador ou celular, usando o modelo Whisper (faster-whisper / whisper.cpp). Nenhum áudio é enviado para servidores nossos ou de terceiros. A transcrição gerada fica apenas no seu dispositivo, e é salva somente quando você escolhe exportá-la (.txt / .srt).

3. Download do modelo de IA

Na primeira vez em que você usa um tamanho de modelo, o aplicativo baixa o modelo de um repositório público (Hugging Face). Nesse momento, os servidores do Hugging Face podem registrar seu endereço IP, conforme a política deles. O modelo fica em cache no seu dispositivo; depois disso, o aplicativo funciona offline.

4. O que o aplicativo NÃO faz

  • Não envia áudio, texto ou metadados para servidores dos desenvolvedores;
  • Não contém publicidade, rastreadores ou telemetria;
  • Não pede cadastro, e-mail ou telefone;
  • Não acessa arquivos além do áudio que você selecionou (e da pasta de cache do modelo).

5. Versão mobile (Android)

O aplicativo Android grava áudio pelo microfone apenas enquanto você usa a função de gravação e transcreve on-device. A permissão de microfone é solicitada pelo sistema e pode ser revogada a qualquer momento nas configurações do Android. Nada é gravado sem sua ação.

6. Site (GitHub Pages)

Este site é estático, hospedado pelo GitHub Pages. Não usamos cookies nem ferramentas de análise. O GitHub pode coletar dados técnicos padrão de acesso conforme a política do GitHub. A página de downloads consulta a API pública do GitHub para listar a versão mais recente.

7. Doações via Pix

Doações são opcionais. Se você doar via Pix, a transação é processada pelo seu banco; não temos acesso a dados bancários. A chave Pix exibida é usada apenas para receber o valor.

8. Crianças e adolescentes

O aplicativo não coleta dados, portanto não há tratamento de dados de crianças ou adolescentes. Recomenda-se o uso acompanhado por responsáveis, conforme a faixa etária indicada na loja de aplicativos.
